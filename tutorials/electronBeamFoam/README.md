# electronBeamFoam tutorials

- `barePlate_singleTrack`: inherited bare-plate geometry for source/calibration checks.
- `barePlate_multiTrack`: 5-track serpentine template. Edit `generateSerpentinePath.py`
  to change track count, hatch spacing, scan speed, beam power and jump time.

These are development templates, not calibrated EPBF benchmark cases.
